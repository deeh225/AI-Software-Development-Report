# Context Engineering

## 1. Definition

Context Engineering is the process of providing useful information and background knowledge to AI so that it can produce better responses.

## 2. Difference Between Prompt and Context

Prompt:
- The instruction given to AI.

Context:
- Additional information that helps AI understand the problem.

Example:

Prompt:
"Fix this code"

Context:
- Programming language
- Error message
- Existing source code
- Project requirements


## 3. Benefits

Context Engineering helps AI:

- Understand projects better
- Generate relevant solutions
- Reduce misunderstanding
