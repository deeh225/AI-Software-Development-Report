# Prompt Engineering

## 1. Definition

Prompt Engineering is the process of designing and improving instructions given to AI models to get better results.

## 2. Importance

A good prompt helps AI:

- Understand requirements clearly
- Generate more accurate answers
- Reduce errors

## 3. Example

Bad prompt:

"Write code"

Better prompt:

"Write a Python program to manage student information using object-oriented programming."

## 4. Prompt Structure

A good prompt usually contains:

- Role
- Task
- Context
- Requirements
- Output format

## 5. Role in Software Development

Developers can use Prompt Engineering to:

- Generate code
- Debug programs
- Create documentation
- Analyze requirements
